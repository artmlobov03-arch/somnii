# Сомний — AI-анализ снов

## Публикация без Terminal

Проект подготовлен для Vercel. Серверные функции в папке `api/` безопасно вызывают OpenAI, а API-ключ хранится только в переменных окружения Vercel.

1. Создай на GitHub приватный репозиторий и загрузи в него файлы проекта, кроме `.env`.
2. Открой https://vercel.com/new, войди через GitHub и импортируй репозиторий.
3. В разделе Environment Variables добавь:
   - `OPENAI_API_KEY` — твой ключ OpenAI;
   - `OPENAI_MODEL` — `gpt-5`.
4. Нажми Deploy. Vercel выдаст обычную ссылку на сайт — её можно открывать на любом устройстве без Terminal.

## Локальный запуск

Для локальной проверки: `npm start`, затем открой `http://localhost:3000`.

Ключ используется только сервером. Не добавляй `.env` в GitHub и не вставляй ключ в HTML.
